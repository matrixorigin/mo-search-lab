# README 截图

这些图片展示 MO Search Lab v0.13.2 的真实界面，供根目录 README 引用。根 README 中四张图统一使用 `width="960"`，高度按原比例显示；保留原始分辨率用于放大查看。

| 图片 | 来源 |
| --- | --- |
| `cli-test-selection.png` | 运行交互式 CLI，在测试列表捕获 112 列 × 24 行的终端输出 |
| `cli-report.png` | CLI 打开已有 GIST1M 报告，捕获 112 列 × 31 行的概览 |
| `html-performance.png` | 从原始 JSON 的副本执行 `render`，浏览器打开生成的离线 HTML |
| `html-environment.png` | 同一 HTML 的运行环境页，展示版本、节点和缓存配置 |

报告使用 2026-10-09 本地 GIST1M 100 万条、960 维公开向量的测量记录，MO 版本为 4.2.1。原始测量工具版本为 v0.12.2，展示与 HTML 渲染版本为 v0.13.2。截图数值用于说明布局，不代表统一性能或质量验收标准。

CLI 图片根据实际终端字符网格渲染，字体和背景是截图时的终端样式；用户的终端可有所不同。HTML 图片来自离线浏览器截图。捕获过程未重跑 SQL，也未修改原始报告。

更新图片时使用当前二进制、公开测试包及本地报告；先把原始 JSON 和环境记录复制到独立目录，再在副本执行 `render`。保持四个文件名不变，并同步这里及根 README 的版本和来源说明。数据包、完整报告和截图依赖不加入 Git。
